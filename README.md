# ATK-BARANG-LAPAS
Inventaris Barang &amp; Alat Tulus Kantor ( ATK ) Kantor Lapas Kelas II B Kota Payakumbuh

Sistem Inventaris Barang LAPAS

Aplikasi web berbasis PHP untuk mengelola inventaris barang dan Alat Tulis Kantor (ATK) di lingkungan Lembaga Pemasyarakatan (LAPAS). Sistem ini membantu proses pencatatan barang, pengajuan barang rusak/habis, hingga pencetakan laporan yang sudah disetujui.

✨ Fitur Utama
Autentikasi Pengguna
Login dengan dua level akses: admin dan user
Registrasi akun baru
Fitur lupa password (reset via username)
Manajemen Barang
CRUD data barang inventaris dengan kode barang otomatis (auto-generate)
CRUD data ATK (Alat Tulis Kantor) dengan kode otomatis
Manajemen Ruangan
Pengelolaan data ruangan dengan kode ruangan otomatis (khusus admin)
Pengajuan Barang & ATK
User dapat mengajukan barang/ATK yang rusak atau habis
Admin dapat meninjau dan menyetujui pengajuan
Laporan
Cetak laporan pengajuan yang telah disetujui, lengkap dengan logo instansi
Manajemen Pengguna (Admin)
Tambah, kelola, dan atur level akses admin/user
Halaman profil pengguna
Log Aktivitas
Pencatatan aktivitas pengguna dalam sistem
Tampilan
Antarmuka responsif dengan Bootstrap 5 dan Font Awesome
Dukungan mode terang (light) dan gelap (dark)
🛠️ Teknologi yang Digunakan
Backend: PHP (native, prosedural) dengan MySQLi
Database: MySQL
Frontend: HTML, CSS, Bootstrap 5, Font Awesome
Struktur: Multi-halaman (multi-page) dengan pemisahan area admin/
